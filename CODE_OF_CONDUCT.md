# Code of Conduct

MolActAgent is intended to be a welcoming, respectful, and technically rigorous project.

Contributors are expected to:

- communicate respectfully and assume good faith;
- focus criticism on ideas, code, data, and evidence;
- welcome people with different backgrounds and levels of experience;
- avoid harassment, discrimination, personal attacks, and publishing private information.

Project maintainers may remove contributions or restrict participation when conduct conflicts with these expectations.
