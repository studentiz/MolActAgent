# Penguins — experimental regression example

**The regression backend remains under development and is not evaluated
in the accompanying manuscript. We share it to support community
exploration and collaboration. Its reliability and applicability require
further validation.**

This directory contains the reference and test tables, feature
descriptions, background and configuration template for the exploratory
body-mass example. The example demonstrates the regression workflow;
it does not establish general regression performance.

Follow the [regression tutorial](../../docs/tutorial.md#11-predicting-continuous-values-regression)
for the commands and implementation details. Read the
[experimental status and limitations](../../docs/experimental-regression.md)
when interpreting its predictions, intervals and confidence scores.

Reproducible evaluations, failure cases and method improvements are welcome.
