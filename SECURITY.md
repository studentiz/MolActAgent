# Security policy

Please do not report credentials, private molecular data, or other sensitive material in a public issue.

If you discover a security problem in MolActAgent, open a private report through the repository's supported GitHub security contact, or contact the maintainers directly before disclosing the issue publicly.

Users are responsible for reviewing their LLM provider's data-retention and privacy terms before sending molecular or experimental data to a remote endpoint. Store credentials in environment variables or ignored local configuration files; never commit them.
